# RU:LC Systems Roblox

Игровой бот сети: **баллы**, **поиск**, **аналитика модерации**.  
CycleRM шлёт наказания сюда — баллы начисляются **только в этом боте**.

## Команды

| Команда | Описание |
|---------|----------|
| `/поиск` | Профиль + история наказаний с листанием |
| `/баллы` | Быстрая карточка баллов |
| `/риск` | Уровень риска игрока (🟢🟡🟠🔴) |
| `/топ` | Топ игроков по баллам |
| `/радар` | Игроки выше порога баллов |
| `/сравнить` | Сравнить двух игроков |
| `/журнал` | Последние наказания на сервере |
| `/статистика` | Сводка модерации сервера |
| `/модератор` | Статистика staff-участника |
| `/staff-топ` | Топ модераторов |
| `/правила` | Таблица баллов |
| `/установить-баллы` | Изменить баллы (Manage Server) |
| `/команды` | Интерактивная справка |

### Шкала риска

| Баллы | Уровень |
|-------|---------|
| 0 | ⚪ Чистый |
| 1–4 | 🟢 Низкий |
| 5–9 | 🟡 Средний |
| 10–14 | 🟠 Высокий |
| 15+ | 🔴 Критический |

## Internal API (для CycleRM)

| Endpoint | Описание |
|----------|----------|
| `GET /health` | Проверка |
| `POST /internal/punishment` | Новое наказание + баллы |
| `POST /internal/punishment/revoke` | Revoke + откат баллов |

Заголовок: `Authorization: Bearer <INTERNAL_API_SECRET>`

## Запуск

```powershell
cd RULC-Systems-Roblox
py -3 -m pip install -r requirements.txt
copy .env.example .env
python main.py
```

**Порядок:** сначала Roblox-бот (порт 8081), затем CycleRM.

В CycleRM `.env`:
```
RULC_ROBLOX_URL=http://127.0.0.1:8081
RULC_ROBLOX_SECRET=<тот же секрет>
```

## Переменные окружения

| Переменная | Описание |
|---|---|
| `DISCORD_TOKEN` | Токен бота |
| `INTERNAL_API_SECRET` | Секрет для CycleRM (Bearer) |
| `INTERNAL_API_HOST` | Хост API (по умолчанию `127.0.0.1`) |
| `INTERNAL_API_PORT` | Порт API (по умолчанию `8081`) |
| `DEV_GUILD_IDS` | Быстрая синхронизация slash-команд |
| `ADMIN_DISCORD_IDS` | Доп. доступ к `/установить-баллы` |
| `DATABASE_PATH` | SQLite (по умолчанию `data/roblox.db`) |
